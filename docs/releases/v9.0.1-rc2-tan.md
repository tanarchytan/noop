Release candidate. The app gains its own identity, a new body-clock age, and a backup that can be restored into any build.

## The app has a new name

NOOP's app identity changed from `com.noop.whoop` to **`com.noop.tan`**.

Every NOOP fork was shipping under the same `com.noop.whoop` identity. Android allows one app per
identity, so installing a second fork either failed outright or, when the signing keys differed, refused
to update. Moving to a distinct identity means this fork installs **beside** any other NOOP build, each
keeping its own separate data.

**This means an existing NOOP install is not upgraded — you get a second app.** Your old data stays in
the old one. To carry it over: in the old app open **Backup & Sync → Export backup file…**, then in this
one **Backup & Sync → Restore from a backup…** and pick that `.noopbak`. Once it's restored you can
uninstall the old app.

## Added
- **Rhythm Age** — a body-clock age computed from the strap's own on-wrist motion, shown in Health with a
  three-line chart tracking it against your actual age and your fitness age. Needs a week of wear before
  it first appears.
- **Date of birth replaces the age wheel**, so scores that depend on age use your exact fractional age.
- **Sleep schedule card** bridges fragments of one night into a single session.
- **Heart-rate recovery** after a hard bout.
- **Personal sleep need and consistency** now feed the Rest score.
- **Recovery Index slope and Activity Balance** feed Recovery.
- **Steps calibration** is a stepper you can actually hit, instead of an undraggable slider.

## Fixed
- **Restoring a backup could quietly quarantine your database** — the restore swapped the file while the
  corruption handler was still holding it. Restores are now staged and applied at startup.
- **A restored database could crash-loop** on open, because it kept the identity of the build it came from.
- **Backups now import from any fork or version** by copying rows on content rather than position.
- **Devices** listed placeholder hardware; it now shows only real bands and lets you delete one.
- **Skin temperature** shows an absolute reading on Home and Compare, not a deviation.
- **Calories** fall back to the strap's own estimate when a bout has none.

## Under the hood
Stress, Rest, sleep debt, steps, day calories, nap detection and raw HRV analysis all moved to the shared
Rust core. The database version space forked to its own line so upstream schema numbers can never collide
with this fork's.
